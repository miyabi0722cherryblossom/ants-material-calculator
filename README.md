# 🐜 素材計算機（ザ・アンツ攻略ツール）

目標の素材があと何日で貯まるかを計算する、シンプルなWebアプリです。
HTML / CSS / JavaScript だけで作られており、外部ライブラリやデータベースは使っていません。

---

## 📱 使い方

1. ページを開く
2. 次の3つを入力する
   - **必要な素材の量**：目標として集めたい合計
   - **今持っている素材の量**：いま手元にある量（0でもOK）
   - **1日に手に入る量**：1日あたり集められる量
3. 「計算する」ボタンを押す
4. 結果が表示されます
   - 不足している素材
   - 到達までの日数
   - 到達予定日

素材がすでに足りている場合は「素材は足りています」と表示されます。

### 計算の仕組み

```
不足素材 = 必要素材 − 所持素材

・不足素材が0以下 → 「素材は足りています」
・不足素材が1以上 → 到達日数 = 不足素材 ÷ 1日の獲得量（小数は切り上げ）
                    到達予定日 = 今日 ＋ 到達日数
```

**例**：必要1,000 / 所持250 / 1日100 → 不足750 / 到達日数8日

## 🚀 Vercel で公開する手順

このアプリは「ビルド不要の静的サイト」なので、設定はほぼ不要です。

### 前提

- GitHubにこのフォルダをアップロード済みであること
- Vercelのアカウントを作成済みであること（GitHubアカウントで登録できます）

### 手順

1. [vercel.com](https://vercel.com) にログインする
2. 「**Add New...**」→「**Project**」を選ぶ
3. このリポジトリ（`ants-material-calculator`）を選んで「**Import**」する
4. 設定画面が出るが、**何も変更せずそのまま**「**Deploy**」を押す
   - Framework Preset：`Other`（自動でそうなります）
   - Build Command：空のままでOK
   - Output Directory：空のままでOK
5. 少し待つと公開完了。`https://〇〇〇.vercel.app` のURLが発行されます

### なぜ設定不要なのか

このアプリは `index.html` を開くだけで動く「ただのファイル」だからです。
プログラムを組み立てる作業（ビルド）が要らないので、Vercelはファイルをそのまま置くだけで公開できます。

## 🔗 WordPressからリンクする

公開後に発行されたURL（例：`https://ants-material-calculator.vercel.app`）を、
WordPressの記事やメニューにリンクとして貼り付ければ完成です。

```html
<a href="https://〇〇〇.vercel.app" target="_blank" rel="noopener">
  素材計算機を開く
</a>
```

`target="_blank"` は「新しいタブで開く」という意味です。
