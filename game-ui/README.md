# 🍊 シーズン果物ショップ シミュレーター

『The Ants: Underground Kingdom（ザ・アンツ）』のシーズン果物ショップを
ゲーム内UI風に再現した、購入シミュレーターです。

HTML / CSS / JavaScript だけで動く静的Webアプリで、
外部ライブラリやデータベースは使っていません。

---

## 📱 使い方

1. ページを開く
2. 上部の「使用可能なシーズン果物」に手持ちの果物数を入力する
3. 各アイテムの **＋ / －** ボタンで購入数を増減する
   - 残り交換回数が 0 になると「交換済」と表示され、それ以上買えません
   - 残り果物が足りないと ＋ ボタンが無効になります
4. ヘッダーに「使用済み」「残り」の果物数が常時表示されます

---

## 🗂 ファイル構成

```
.
├── index.html      … ページ本体
├── style.css       … ゲームUI風スタイル
├── script.js       … 増減・集計ロジック（21アイテム定義を含む）
└── images/         … 各アイテム画像（item-01.png 〜 item-21.png）
```

アイテムの内容（数量・価格・交換回数）は `script.js` 冒頭の
`ITEMS` 配列で管理しています。

---
